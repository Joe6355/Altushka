# Просмотр анимаций Алисы

**Unity 6000.6.8f1, Universal 2D / URP.** Открыть `Assets/Scenes/AlisaPreview.unity`, нажать Play. Меню `Alisa → Открыть сцену просмотра` открывает эту же сцену.

## Настройки пикселей

- Ячейка: **36×86**, без обрезки и изменения пропорций.
- Pixels Per Unit: **16**. Это масштаб мира Unity, а не изменение размера PNG.
- Point, Full Rect, без сжатия, mipmaps и масштабирования NPOT.
- Привязка стоп взята из JSON исходного набора. У зеркального бокового ракурса это `(17,85)`, у большинства клипов `(18,85)`, у танца `(15,85)`.
- Игровая камера использует целочисленный масштаб и округляет отображаемое положение к сетке пикселей. Можно включить крупный план или полный игровой фон 320×240.
- Спрайты используют URP 2D Unlit, без постобработки и сглаживания.

## Animator и персонаж

`Assets/Alisa/Prefabs/Alisa.prefab` содержит корневые `Animator` и `AlisaActor`, дочерний `Visual` со `SpriteRenderer` и отдельную тень. Анимационные кривые меняют только спрайт в `Visual`; размер персонажа и корневая позиция не анимируются.

`Assets/Alisa/Animations/Alisa.controller` содержит группы ракурсов и состояния всех импортированных клипов. Целочисленный параметр **AnimationIndex** переключает состояние через `Any State` без смешивания кадров. В редакторе можно открыть контроллер и следить за активным состоянием во время Play.

`AlisaActor.Select(key)` запускает клип через Animator. Ключи и числовые ID перечислены в `Assets/Alisa/Art/AlisaSources.json` и `AlisaLibrary.asset`. Например:

```csharp
actor.Select("RearRedraw/walk_back");
actor.Select("Side/walk_side_right");
actor.Select("Front/dance_original");
```

В просмотре доступны настоящие исходные задержки кадров, включая неодинаковые длительности idle. В `.anim` записан также конечный ключ, чтобы последняя ячейка сохраняла полную длительность. Пауза и прокрутка времени работают через Animator; отдельного проигрывателя, подменяющего ему спрайты, нет.

## Обновление исходников

Из корня репозитория:

```powershell
python tools/sync_unity_art.py
```

Затем в Unity выбрать **Alisa → Обновить клипы из атласов**. Скрипт копирует готовые PNG без изменения байтов и собирает описание кадров из исходных JSON. Существующие ID клипов, GUID нарезанных спрайтов и ссылки на Unity-ассеты сохраняются. PNG в `Art/` — импортируемые копии; рисовать и менять тайминг нужно в исходных наборах `alisa/` или `recolor/`.

Обновление меняет генерируемые клипы, библиотеку, параметры импорта и ссылки в префабе. Существующая сцена не пересоздаётся; пользовательские объекты и настройки сцены сохраняются. При обычном открытии готового проекта генератор не запускается.

**Alisa → Проверить импорт и Animator** проверяет размеры, хеши атласов, настройки импорта, длительности, зацикливание и каждый кадр каждого клипа через Animator на экземпляре префаба. Для пакетной проверки:

```powershell
Unity.exe -batchmode -projectPath <путь-к-Alisa2D> -executeMethod AlisaGame.Editor.AlisaProjectBuilder.BuildAndVerify -quit -logFile <путь-к-логу>
```

## Текущие ограничения материала

Новая спина содержит ходьбу и опорные позы. Задняя неподвижная стойка импортирована отдельно из исходного референса и явно подписана как один кадр. Задние диагонали и прямой фронтальный цикл ещё не нарисованы в качестве этой новой основы. Поэтому режим WASD выбирает ближайший существующий ракурс; диагональное перемещение само по себе не означает, что для него уже создан новый рисунок.

Архивные задние клипы проигрываются на месте, без движения из прежних демонстрационных роликов. Их можно включить для сравнения. Глазные варианты относятся к исходному танцу; рабочие циклы ходьбы используют основной вариант с голубыми глазами.

Unity-проект и его изменения хранятся в том же репозитории, что и исходные ассеты. `Library`, `Temp`, `Logs`, `UserSettings`, сборки и локальная установка редактора в Git не попадают.
