# Алиса — ассеты и Unity-проект

Персонаж для 2D-игры: **36×86 пикселей**, белое каре, чёрная кофта, белая юбка, тёмные чулки и голубые глаза. Исходный танец и варианты глаз сохранены отдельно.

## Запустить игру

Проект — [`unity/Alisa2D`](unity/Alisa2D), **Unity 6.6 / 6000.6.8f1**, Universal 2D / URP. На этом ПК редактор установлен в `C:\Unity\6000.6.8f1`.

Запустить [`Open-Alisa.cmd`](Open-Alisa.cmd) или открыть проект через Unity Hub. Основная сцена — **`Assets/Scenes/Gameplay.unity`**. Нажать Play и кликнуть по Game.

**WASD / стрелки** — ходьба, отпускание клавиш — idle. **Space** в стойке — включить или выключить танец; движение его прерывает. Поддерживается геймпад.

Сцена организована в World, Actors и Main Camera. Алиса — управляемый префаб с Rigidbody2D, коллайдером стоп, стандартным PlayerInput и состояниями Idle / Walk / Dance в Animator. Последний боковой цикл используется при обычной ходьбе. Камера выводит один полный кадр через штатный Pixel Perfect Camera.

Настройка управления, Animator и добавление следующих анимаций: [`unity/Alisa2D/README.md`](unity/Alisa2D/README.md).

## Ассеты

| Папка | Содержимое |
| --- | --- |
| `original/` | Исходная анимация. |
| `recolor/` | Перекраска, Aseprite, атласы и варианты глаз. |
| `alisa/side_revision/` | Последняя проба бокового шага: 12 кадров, Aseprite, сравнение и проход по полу. |
| `alisa/motion_polish/` | Предыдущий набор восьми направлений для дальнейшей правки и сравнения. |
| `alisa/side_walk/` | Прежний согласованный боковой рисунок и исходники. |
| `alisa/motion_next/` | Передние диагонали и сохранённый исходный танец. |
| `alisa/rear_key_redraw/` | Предыдущая задняя основа. |
| `unity/Alisa2D/` | Игровой проект, сцена и префаб персонажа. |

Рисунки и анимации продолжают дорабатываться. Прежние варианты сохранены в исходных папках, готовые .anim доступны в Unity через Project и Animation.

Ассеты и проект ведутся вместе в [Joe6355/Altushka](https://github.com/Joe6355/Altushka). В Git включены Assets с .meta, Packages и ProjectSettings; кэш редактора и локальные сборки исключены.
