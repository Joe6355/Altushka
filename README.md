# Алиса — ассеты и Unity-проект

Персонаж для 2D-игры. Нативная ячейка **36×86 пикселей**: белое каре, чёрная кофта, белая юбка, тёмные чулки и голубые глаза. Исходный танец сохранён; варианты с зелёными и красными глазами лежат отдельно.

## Смотреть в Unity

Проект: [`unity/Alisa2D`](unity/Alisa2D). Редактор **Unity 6.6 / 6000.6.8f1**, Universal 2D / URP.

На этом ПК можно запустить [`Open-Alisa.cmd`](Open-Alisa.cmd) двойным кликом: он откроет проект и сцену Алисы в установленном редакторе. Затем нажать **Play**. Редактор установлен в `C:\Unity\6000.6.8f1`.

1. В Unity Hub нажать **Add → Add project from disk** и выбрать папку `unity/Alisa2D`.
2. Открыть сцену `Assets/Scenes/AlisaPreview.unity` и нажать **Play**.
3. Выбирать клипы слева. По умолчанию включён новый фронтальный idle. Есть пауза, шаг по кадрам, ползунок времени, скорость, крупный план и игровой фон.

`Space` — исходный танец; `P` — пауза; `,` и `.` — предыдущий/следующий кадр; `R` — вернуть персонажа в центр; `F1` — скрыть панель. Кликнуть по окну Game и нажать WASD или стрелки: Алиса сразу пойдёт, а после отпускания клавиш перейдёт в idle. Галочка для включения движения не нужна. При начале ходьбы камера показывает всю карту и остаётся на месте.

Персонаж находится в `Assets/Alisa/Prefabs/Alisa.prefab`, контроллер — в `Assets/Alisa/Animations/Alisa.controller`. Все клипы — обычные Unity `.anim` с кривой `Visual → SpriteRenderer.sprite`. Состояния сгруппированы по ракурсам; параметр `AnimationIndex` выбирает клип. Переходы имеют нулевую длительность, чтобы не смешивать пиксельные кадры. Полный список идентификаторов и ссылок на клипы хранит `AlisaLibrary.asset`.

Подробности импорта и обновления: [`unity/Alisa2D/README.md`](unity/Alisa2D/README.md).

## Что уже есть

| Папка | Содержимое |
| --- | --- |
| `original/` | Исходная анимация. |
| `recolor/` | Перекрашенная анимация, Aseprite, атласы и варианты глаз. |
| `alisa/motion_polish/` | Текущий общий набор: idle и ходьба в 8 направлениях, 96 кадров, Aseprite и превью. |
| `alisa/rear_key_redraw/` | Предыдущая задняя основа для сравнения. |
| `alisa/side_walk/` | Предыдущие боковые idle и ходьба вправо/влево. |
| `alisa/motion_next/` | Предыдущие передние диагонали, старт, остановка, поворот и сохранённый исходный танец. |
| `unity/Alisa2D/` | Unity-проект со сценой просмотра, персонажем и Animator. |

В `alisa/` также сохранены прежние эксперименты. В Unity предыдущие циклы доступны под переключателем архива.

Новые циклы содержат прямые фронтальный и задний ракурсы, боковые виды и четыре диагонали. При смене направления ходьба сохраняет фазу шага. Кадры приведены к одной палитре и общим ориентирам головы, талии, подола и стоп. Исходный танец сохранён без изменений. Набор готов к просмотру и следующим правкам в Unity.
