# Алиса в Blender

Исправленная проба лежит в [revision](revision/). Рисунок головы и кофты перенесён с кадра исходного танца на объёмные поверхности. Текстура рассчитана на переднюю правую диагональ. В этой папке лежат модель Blender, сравнение, цикл на игровом дворе и спрайты 36×86 для Aseprite.

## Игровые диагонали

[game](game/) содержит обе передние диагонали для Unity. На каждую сторону приходится 20 кадров ходьбы по 50 мс и 6 кадров стойки по 200 мс. Левая сторона отражена со сдвигом на полцикла. Проекция стоп и темп Animator рассчитаны на игровую скорость 37,5 px/с. В ролике Алиса проходит вправо, меняет диагональ на шаге и останавливается.

Для повторного экспорта запусти `source/render_game_diagonals.py` с открытым `revision/Alisa.blend`. Затем выполни `source/export_game_diagonals.py` через Python и обнови атласы в Unity обычным импортом проекта.

## Первая проба

Модель с белым каре, голубыми глазами, чёрной кофтой, белой юбкой и графитовыми чулками. Открой `Alisa.blend` и нажми пробел, чтобы посмотреть цикл на месте. У модели есть скелет, отдельные материалы и ключи для движения юбки, волос и кофты.

Проба для игры показывает ходьбу вниз и вправо. В атласе 15 кадров по **36×86 px**. Тег `walk_se` длится ровно секунду. Точка привязки на уровне пола находится в 18,56 px от левого и 80,68 px от верхнего края кадра. За цикл она перемещается примерно на 24 px вправо и 9 px вниз в проекции камеры.

- `Alisa_model.png` показывает модель с трёх сторон и спрайт крупным планом.
- `Alisa_walk.aseprite` содержит кадры и тег ходьбы. Рядом лежат PNG-атлас и JSON с координатами и длительностями.
- `Alisa_walk.mp4` и `Alisa_walk.gif` показывают четыре цикла на фоне игрового двора.

## Повторный экспорт

Открой `Alisa.blend` в Blender 5.1 и выполни `source/render_frames.py`. Рендеры сохраняются в `.tools/alisa_blender`. Запусти `source/export_sprites.py` через Python с Pillow и NumPy. Скрипт вызывает установленный Aseprite для сборки атласа и использует видеокодер проекта для MP4. Путь к другому экземпляру Aseprite можно передать через `--aseprite`.

`source/build_model.py` пересоздаёт исходную модель со скелетом и первым циклом. Для новых спрайтов из отредактированной модели достаточно повторить экспорт из сохранённого файла.
