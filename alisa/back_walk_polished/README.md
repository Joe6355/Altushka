# Алиса — доработка задних ракурсов

Три направления: прямо от камеры и обе задние диагонали. Нативный размер остался **36×86 пикселей**. Эта версия дорабатывает `../back_walk/`; одобренный боковой набор находится в `../side_walk/`.

## Изменения

- Цикл увеличен с10 до16 отдельных поз. Кадр шага длится60мс, весь цикл960мс: два шага почти за секунду. Частота нативных поз согласована с видео50кадров/с без чередования длительности показов.
- Заново заданы контуры коленей, икр, лодыжек и обуви. Один рисунок ботинка используется в стойке, шаге и переходах; на подъёме пятки видна тёмная подошва.
- Голова стабилизирована относительно корпуса. Плечи и таз движутся с разными фазами, концы волос следуют с задержкой. Небольшой край щеки в диагоналях сохраняет исходные пиксели.
- Пояс юбки следует тазу, подол и отдельные складки запаздывают; над работающим бедром край приподнимается на1пиксель. Уточнены белые и серые кластеры волос и подола.
- Старт содержит9поз с переносом веса на опорную ногу. Остановка тоже содержит9поз: тело продолжает движение над поставленной ногой, вторая нога делает закрывающий шаг. Длительности постепенно увеличиваются, чтобы замедление было видно.
- Добавлены отдельные четырёхкадровые повороты. Голова поворачивается первой, затем плечи и ноги. Крайние кадры совпадают с idle соответствующих ракурсов.
- Добавлены небольшие контактные тени под опорными стопами.

## Перемещение в игре

`Alisa_back_polished.json` содержит кадры, длительности, теги и привязки. Обычная привязка `(18,85)`, у зеркальной левой диагонали `(17,85)`. У поворотов привязка `(18,85)`; их крайние позы уже согласованы с этими различиями.

В каждом кадре `rootOffset` задаёт смещение тела относительно начала клипа, а `footContacts` — опорные точки в координатах ячейки. В теге цикла `rootCycleDisplacement` задаёт полный перенос за один цикл. При повторе добавляй его к смещениям следующего цикла. При остановке и диагональном старте также применяй `rootOffset`: он нужен для сохранения опорной стопы на месте. Эти движения тела хранятся отдельно от рисунка, чтобы сохранить холст36×86 без обрезки головы. В ролике и GIF переходов они уже применены.

При шагах каждые60мс тело перемещается на `(0,-1)` для прямого движения от камеры и `(±2,-0,5)` для диагоналей. Для отрисовки положения используется `floor(value+0.5)`. При остановке смещение уменьшается, а длительности кадров увеличиваются.

Последний кадр старта совпадает с контактом0 ходьбы. После старта продолжай ходьбу с локальной позы1. Останавливай на контакте0, затем показывай stop с локальной позы1, отсчитывая его `rootOffset` от текущего положения. Крайние позы оставлены в полных тегах для удобства редактирования; сцена не повторяет контакт дважды.

`Alisa_back_polished_timeline.json` хранит полную последовательность ролика с координатами тела. Фон сохранён в `Alisa_scene_background.png`.

## Исходники и проверка

Нативные основы взяты из сохранённых задних ракурсов `../back_walk/source/`. Их исходные референсы и промпты находятся там же. В этой итерации доработаны существующие слои и отдельные пиксельные позы. `source/cels.py` хранит их контуры, палитру, движения слоёв и перемещение тела; `source/build.py` экспортирует файлы и сцену.

Из корня проекта, Python с Pillow и NumPy:

```powershell
python alisa/back_walk_polished/source/build.py
python alisa/back_walk_polished/source/build.py --render
python alisa/back_walk_polished/source/build.py --verify-video
```

Для MP4 используются FFmpeg DLL установленного Blender5.1. Проверены все130кадров Aseprite: слои прочитаны обратно, собраны и побайтно сравнены с PNG-атласом. Проверены крайние позы старта/остановки и поворотов, опорные точки во время ходьбы и замедления, фиксация стопы в конце закрывающего шага, зеркальность направлений и сохранность края лица. Ролик проверен декодированием785кадров и сравнением временных меток и изображения с исходным рендером.
