# Алиса — боковой ракурс и ходьба

Кадр **36×86 пикселей**, как у исходной Алисы. Боковой вид с небольшим обзором сверху: один видимый голубой глаз смотрит по направлению движения. Сохранены белое каре с завитком, чёрная кофта, белая юбка, тёмно-серые чулки с чёрным контуром и исходные ориентиры пропорций. Новая поза добавлена отдельно от уже одобренных передних диагоналей.

## Просмотр

- `Alisa_side_walk.mp4` — пять секунд ходьбы вправо на прежнем игровом фоне; 1280×960, 50 кадров/с, увеличение исходной сцены320×240 в четыре раза без сглаживания.
- `Alisa_side_walk.gif` — цикл крупным планом в обе стороны, 10 кадров по100мс.
- `Alisa_side_idle.gif` — боковой idle в обе стороны.
- `Alisa_side_model.png` — сравнение исходной стойки, боковой стойки и бокового шага.
- `Alisa_side_idle.png` — прозрачная боковая стойка36×86.

В этом этапе проверяется именно боковой ракурс и цикл шага. Переходы к передним диагоналям и вид со спины будут следующим этапом; в ролике нет смены ракурса.

## Для Aseprite и игры

`Alisa_side.aseprite` содержит28 кадров, четыре тега и шесть отдельных слоёв: дальняя нога, таз, ближняя нога, юбка, кофта, голова. Можно править каждый слой покадрово.

| Тег | Кадры | Длительность |
| --- | ---: | --- |
| idle_side_right | 0–3 | 2,4с, цикл |
| walk_side_right | 4–13 | 1с, цикл |
| idle_side_left | 14–17 | 2,4с, цикл |
| walk_side_left | 18–27 | 1с, цикл |

`Alisa_side_atlas.png` — прозрачный атлас360×258: десять столбцов, три строки, ячейка36×86, последние две ячейки пустые. `Alisa_side.json` хранит координаты, длительности, теги и точки привязки.

Привязка правого ракурса `(18,85)`, зеркального левого `(17,85)`. Разница поX сохраняет отражённую точку опоры. Скорость в демонстрации40 исходных пикселей/с: поза и положение обновляются каждые100мс, шаг корня4 пикселя. Опорный носок в фазах0–5 занимает одну точку игрового пола. Дальняя нога сдвинута на2 пикселя влево и на1 вверх для читаемости глубины.

Лицо не перерисовывается между кадрами. Движение корпуса — до2 пикселей по вертикали, груди — ещё1 пиксель с задержкой, подола — до2 пикселей с закреплённым поясом; завиток волос отклоняется на1 пиксель. Руки остаются на бёдрах, как в одобренном цикле.

## Исходники

Для новой боковой опорной позы использован встроенный `image_gen.imagegen` с исходной Алисой как референсом. Результат приведён к нативной сетке и палитре20 цветов. Волосы и лицо доработаны в пикселях; десять контуров ног, тени и движения слоёв заданы в `source/profile.py`. Левый ракурс зеркален правому. Исходные кадры предыдущих версий не изменены.

`source/Profile_reference_generated.png` — исходная сгенерированная опорная поза; `source/Profile_native.png` — её нативная основа. `source/prepare_native.py` воспроизводит перевод основы в сетку36×86 и палитру. `source/Alisa_input_reference.png` хранит использованный референс из исходных кадров. Полный промпт и способ генерации находятся в `source/imagegen_prompt.txt`.

Сборка из корня репозитория, Python с Pillow и NumPy:

```powershell
python alisa/side_walk/source/build.py
python alisa/side_walk/source/build.py --render
python alisa/side_walk/source/build.py --verify-video
```

Первый запуск экспортирует Aseprite, PNG, JSON и GIF. `--render` дополнительно создаёт и проверяет MP4; для кодирования и декодирования используются FFmpeg DLL установленного Blender5.1. Все28 кадров Aseprite прочитаны обратно по слоям и побайтно сравнены с атласом. Дополнительно проверяются точка опоры, неизменность лица и зеркальное соответствие направлений.
