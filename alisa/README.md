# Рабочие анимации Алисы

Нативный размер —36×86пикселей. Исходный образ с голубыми глазами и белой юбкой находится в `../recolor/blue_eyes/`.

| Набор | Что содержит |
| --- | --- |
| [side_revision](side_revision/README.md) | Текущая проба: один боковой шаг на прежнем рисунке, 12 кадров, сравнение и проход по полу. |
| [motion_polish](motion_polish/README.md) | Отклонённый общий набор 8 направлений, сохранён для сравнения. |
| [walk_redo](walk_redo/README.md) | Одобренный проверочный цикл передней левой диагонали с исходными пикселями верха. |
| [motion_next](motion_next/README.md) | Обе передние диагонали, idle, старт, остановка, смена стороны и исходный танец в одной сцене. |
| [side_walk](side_walk/README.md) | Одобренные боковые ракурсы: ходьба вправо/влево и idle, Aseprite с отдельными слоями. |
| [rear_key_redraw](rear_key_redraw/README.md) | Новая основа заднего цикла:4отрисованные опорные позы,8кадров и проверка на месте. |

В Unity боковая ходьба использует `side_revision`, боковой idle — рисунок `side_walk`, остальные шесть направлений — доступные клипы `motion_polish`. Исходный танец включается игровым действием. Переходы Idle / Walk / Dance и направления подключены в обычном Animator; игровая сцена — `Gameplay`.

Папки `ring_combo`, `locomotion`, `game_topdown`, `back_walk`, `back_walk_polished` и остальные прежние наборы сохранены для сравнения. В Unity они доступны под переключателем архива.
