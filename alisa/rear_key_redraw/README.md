# Алиса — новый задний цикл по ключевым позам

Отдельная проверка новой основы для вида со спины: четыре заново отрисованные опорные позы и восьмикадровый цикл на их основе. Нативный размер **36×86 пикселей**. Поза рук на бёдрах, белое каре с завитком, чёрная кофта, белая юбка и тёмные чулки сохранены.

## Просмотр

- `Alisa_rear_four_keys.png` — контакт, принятие веса, перенос ноги и выход в следующий шаг. Увеличение без сглаживания.
- `Alisa_rear_redrawn.gif` — полный задний цикл крупным планом:8кадров по120мс, всего960мс.
- `Alisa_rear_redrawn.mp4` — проверка цикла **на месте** на игровом фоне, крупный план576×672,50кадров/с,4,8с. В нём пять повторов цикла.
- `Alisa_rear_comparison.gif` — прежняя геометрическая версия слева, новая основа справа. Обе показаны со своими длительностями кадров и одинаковым периодом960мс.

Этот пакет сосредоточен на рисунке и механике одного заднего цикла на месте. Общая сцена с перемещением по карте, задними диагоналями, стартом и остановкой остаётся отдельным этапом.

## Что изменено в основе

Четыре ключа отрисованы заново по объёмной позной схеме. В схеме длины бедра и голени постоянны, колени сгибаются вперёд в глубину, а обувь поворачивается вместе со стопой. Для рисунка использованы одобренный боковой образ Алисы и её исходная задняя стойка.

В нативном цикле сохранены контуры ног, икры, лодыжки, обувь и складки из новых рисунков. Прежнее построение ног по геометрическим сечениям заменено подготовленными рисунками. Используется одна общая калибровка к исходным ориентирам головы, талии, подола и чулок для всех поз. Голова берётся из одного рисунка, чтобы её форма и завиток сохранялись между кадрами; в позе принятия веса добавлено опускание на1пиксель. Второй полушаг отражает корпус и ноги, сохраняя рисунок головы.

Метод сравнения объёмов и последовательного согласования ракурсов сверялся с [SLYNYRD, Pixelblog55 — Top Down Character Animation](https://www.slynyrd.com/blog/2025/3/24/pixelblog-55-top-down-character-animation). Объёмная схема для этих четырёх поз создана отдельно для Алисы; сторонние персонажи в ассет не включены.

## Aseprite и атлас

- `Alisa_rear_redrawn.aseprite` —12кадров,2тега,5слоёв: правая нога, левая нога, юбка, кофта, голова.
- `Alisa_rear_redrawn_atlas.png` — прозрачный атлас144×258:4столбца и3строки, ячейка36×86.
- `Alisa_rear_redrawn.json` — координаты, длительности, слои и теги.

| Тег | Кадры | Назначение |
| --- | ---: | --- |
| key_poses_back | 0–3 | четыре ключа, по240мс, один просмотр |
| walk_back | 4–11 | полный цикл, по120мс, повтор |

Первая строка атласа содержит четыре ключа, следующие две — полный цикл. Привязка `(18,85)`. Анимация помечена `rootMotion: in_place`; перемещение персонажа задаётся игровым контроллером.

## Исходники

Для отрисовки применён встроенный `image_gen.imagegen`. Полный промпт, роли референсов и первоначальная отбраковка записаны в `source/imagegen_prompts.txt`. Выбранная исходная картинка — `source/Rear_keys_guided_generated.png`; её нативный импорт, палитра и слои описаны в `source/redraw.py`.

`source/Rear_pose_guide.png` — объёмная схема, `source/pose_guide.py` воспроизводит её в Blender5.1. Первый невыбранный рисунок сохранён в `source/studies/` для сравнения.

Сборка из корня проекта, Python с Pillow и NumPy:

```powershell
python alisa/rear_key_redraw/source/build.py
python alisa/rear_key_redraw/source/build.py --render
python alisa/rear_key_redraw/source/build.py --verify-video
```

Для MP4 используются FFmpeg DLL установленного Blender5.1. Проверены12кадров Aseprite: слои прочитаны обратно и побайтно сравнены с PNG-атласом. Нативные кадры36×86 используют бинарную прозрачность. MP4 проверен декодированием240кадров, сравнением временных меток и изображения с исходным рендером.
