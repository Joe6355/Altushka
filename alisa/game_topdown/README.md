# Алиса: игровые анимации

Кадр — 36×86 пикселей. Внешность основана на исходной Алисе: белые волосы, голубые глаза, чёрная кофта с вырезом, белая юбка, тёмные чулки. Сохранены вытянутые пропорции фигуры. Ракурс рассчитан на игру с небольшим видом сверху.

## Файлы

- Alisa_game.aseprite — 64 кадра, 8 тегов, отдельные слои «Тело» и «Голова».
- Alisa_game_atlas.png — прозрачный атлас 288×688, сетка 8×8 без отступов.
- Alisa_game_atlas.json — координаты кадров, длительности, теги, опорная точка.
- Alisa_model.png — четыре базовых ракурса, каждый 36×86, порядок: вниз, вправо, вверх, влево.
- Alisa_preview.gif — сверху idle, снизу ходьба; все четыре направления одновременно.
- Alisa_idle.mp4 — idle во всех направлениях.
- Alisa_walk.mp4 — ходьба во всех направлениях.
- Alisa_movement.mp4 — пример перемещения по площадке и смены направления.
- Alisa_prompts.txt — промпты и сведения о референсах.

## Анимации

| Тег | Кадры Aseprite, с 1 | Длительность цикла |
| --- | --- | --- |
| idle_down | 1–8 | 2880 мс |
| idle_right | 9–16 | 2880 мс |
| idle_up | 17–24 | 2880 мс |
| idle_left | 25–32 | 2880 мс |
| walk_down | 33–40 | 960 мс |
| walk_right | 41–48 | 960 мс |
| walk_up | 49–56 | 960 мс |
| walk_left | 57–64 | 960 мс |

В JSON кадры нумеруются с нуля. Ходьба — 8 кадров по 120 мс.
Idle — мягкое дыхание с двумя состояниями высоты верхней части тела; восемь кадров задают паузы и ритм. Ступни остаются на месте. Моргание в этой версии не добавлено.
Левое направление зеркально правому. Голова внутри каждого направления одинаковая между кадрами; она следует небольшому движению корпуса.

## Импорт

Опорная точка стоп: x=18, y=85 внутри кадра. Обрезка кадров отключена, размеры всегда одинаковые.
Для пиксельного отображения используй nearest / point filtering и целочисленный масштаб.
Альфа-канал PNG содержит только 0 и 255: края полностью прозрачные или непрозрачные. Фон и тень из видео в атлас не входят.

## Референсы

Исходный персонаж: recolor/blue_eyes/Altushka_blue_atlas.png.
Позы подготовлены встроенным image_gen и зарегистрированы на исходной пиксельной сетке; исходные крупные генерации сохранены отдельно в generated_images.
Для движения использованы учебные материалы SLYNYRD / Raymond Schlitter:
- https://www.slynyrd.com/blog/2019/10/21/pixelblog-22-top-down-character-sprites
- https://www.slynyrd.com/blog/2020/1/23/pixelblog-25-motion-cycles

Чужие персонажи и изображения референсов в игровые файлы не включены.
