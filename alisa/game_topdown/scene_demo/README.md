# Алиса — цельная игровая сцена

Alisa_full_scene.mp4 — 32 секунды, 1280×960, 50 кадров/с.
Одна непрерывная сцена с неподвижной камерой: idle, ходьба по всем четырём направлениям, подготовка к танцу, исходный танец и возвращение в idle.

Персонаж остаётся на сетке 36×86. В кадре используется целочисленное увеличение в 4 раза.
Ходьба и idle взяты из текущего игрового атласа Alisa_game_atlas.png.
Танец — исходные 40 кадров из recolor/blue_eyes/Altushka_blue_atlas.png: голубые глаза, белая юбка. Показаны два полных повтора по четыре секунды. Сами танцевальные кадры не перерисовывались.

## Время для правок

- 00:00–00:01.44 — начальный idle.
- 00:01.44–00:05.12 — поворот, ходьба вправо, остановка.
- 00:05.12–00:08.80 — ходьба вверх и остановка.
- 00:08.80–00:12.48 — ходьба влево и остановка.
- 00:12.48–00:16.16 — ходьба вниз и остановка.
- 00:16.16–00:19.52 — возвращение к центру, поворот и короткий idle.
- 00:19.52–00:20.32 — переход в танец.
- 00:20.32–00:28.32 — исходный танец, два повтора.
- 00:28.32–00:29.12 — выход из танца.
- 00:29.12–00:32.00 — финальный idle.

## Файлы

- Alisa_full_scene.mp4 — основной ролик.
- Alisa_scene_poster.png — кадр сцены в разрешении видео.
- Alisa_scene_background.png — фон на исходной сетке 320×240.
- Alisa_dance_entry_atlas.png — восемь подготовительных поз 36×86, горизонтальная полоса.
- Alisa_scene_timeline.json — полный порядок состояний, время и координаты.
- Alisa_scene_prompts.txt — промпты новых изображений.
- source/ — сборка ролика и вспомогательные модули.

Фон двора и промежуточные позы подготовлены встроенным image_gen. Переходы между существующими состояниями собраны на родной пиксельной сетке; при поворотах используется одна текстура лица за раз.

Для повторного вывода на этом ПК: запусти source/render_scene.py с параметром --render через Python с numpy и Pillow. Код использует библиотеки FFmpeg из установленного Blender 5.1.
