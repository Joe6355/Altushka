# Алиса — проверка опоры в диагональном шаге

Проверочный цикл для передних диагоналей **A+S / D+S**. Нативная ячейка **36×86**, PPU 16, привязка `(18,85)`. Ходьба: 12 кадров по 80 мс, 960 мс/цикл. Это один отредактированный цикл и его зеркальный вариант; прочие направления сохраняют предыдущие клипы.

В прежней диагонали колено свободной ноги уходило назад, а носок опорной ноги смещался вместе с персонажем по полу. Здесь колено ведёт перенос вперёд, голень и стопа следуют за ним. Контакт, оседание, проход ноги и подъём корпуса согласованы по фазам. Контуры ног редактируются отдельно от модели.

Для скорости 37,5 пикселя/с в диагонали шаг корня за 80 мс равен `(-2.121,+2.121)`. В контрольных фазах 2–6 носок сдвигается на противоположный вектор, поэтому его округлённая позиция на полу остаётся `(10,85)` относительно начала прохода. Точки и проверяемые пиксели записаны в `source/stance_trace.json`. Это проверка опоры на выбранных кадрах, не гарантия художественного качества всей анимации.

Лицо и волосы скопированы без перерисовки из v3. Обе стойки совпадают с прежними покадрово. A/D и исходный танец не изменяются; прежний полный набор v3 сохранён отдельно. Новых генераций imagegen в этой правке нет: использованы редактируемые Aseprite-ассеты текущего персонажа.

Механику переноса, контакта пятки/носка и чередования двух ног сверял по авторскому [разбору Manning Leonard Krull](https://manningkrull.com/__pixel-art/walking.php). Графика референса в ассеты не копировалась.

## Редактировать и собрать

`source/Legs_sw.aseprite` содержит 12 фаз в двух слоях: дальняя и ближняя нога. Это редактируемая основа шага. PNG `Head_sw`, `Torso_sw`, `Skirt_sw` — сохранённые части текущей модели. Обычная сборка читает их и сохранённые ноги; не пересоздаёт их поверх ручных правок.

```powershell
& 'C:/Program Files (x86)/Steam/steamapps/common/Aseprite/Aseprite.exe' --batch --script-param "root=$((Get-Location).Path)" --script 'alisa/step_contact/source/build.lua'
python alisa/step_contact/source/export_video.py
python tools/sync_unity_art.py
```

Только для восстановления начальных контуров ног добавить к вызову Aseprite `--script-param redraw=true`: этот параметр заменит `source/Legs_sw.aseprite`. Обычному редактированию он не нужен.

В Unity: остановить Play, **Assets → Refresh**, затем **Alisa → Применить проверочную походку**. Команда подключает StepContact к двум передним диагоналям Idle/Walk и выставляет начальный взгляд вниз-влево. Остальные направления, сцена, физика и управление сохраняются. Смотреть новый шаг на **A+S / D+S**.

Проверки: бинарная прозрачность; связный силуэт; пиксели головы; точные отражения со сдвигом на шесть фаз; совпадение прежних idle; пять неподвижных опорных точек; направление колена относительно голеностопа; семь хешей принятых исходников и Unity-клипов. MP4 обратно декодированы: 98 кадров / 8,88 с и 90 кадров / 8,80 с, максимальная проверенная ошибка YUV — 1. Unity-каталог содержит 14 атласов, 86 клипов и 713 исходных спрайтов.
