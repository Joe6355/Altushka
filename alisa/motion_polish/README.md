# Алиса — общие циклы движения

Новый набор для просмотра и дальнейшей полировки в игре: **36×86 пикселей**, 8 направлений, **16 циклов и 96 кадров**. Сохранены белое каре с завитком, голубые глаза, чёрная кофта, белая юбка, тёмные чулки с обводкой и исходные ориентиры фигуры.

Ходьба получила отдельные контактные позы, принятие веса, сгибание колена и перенос ноги. Корпус принимает вес, подол и волосы меняют положение по циклу. Прямой вид на камеру и задние диагонали включены в общий набор. Пять основных ракурсов подготовлены отдельно; три левых получены отражением, со сдвигом ходьбы на полушага для согласования опорной ноги.

## Файлы

- `Alisa_motion_polished.aseprite` — 96 кадров, 16 тегов, 4 слоя: ноги, юбка и пояс, кофта и руки, голова. Слои разделены по высоте ячейки; скрытые части тела отдельно не дорисовывались.
- `Alisa_motion_polished_atlas.png` — прозрачный атлас **288×1032**, 8 столбцов × 12 строк. Каждая ячейка строго 36×86.
- `Alisa_motion_polished.json` — прямоугольники, задержки, теги и привязки.
- `Alisa_walk_polished.gif` — все направления на игровом фоне, цикл 800 мс.
- `Alisa_idle_polished.gif` — idle всех направлений, цикл 2400 мс.
- `Alisa_motion_polished.mp4` — ходьба и idle на игровом фоне: 7,2 с, 1280×960, целочисленное увеличение в 4 раза. Это проверка циклов на месте; перемещение доступно в Unity.
- `Alisa_turnaround.png` — ракурсы в стойке.
- `Alisa_native_walk_review.png` — покадровый просмотр пяти основных циклов с целочисленным увеличением.

Направления идут по порядку `s, se, e, ne, n, nw, w, sw`. Для каждого сначала 4 кадра `idle_*` с задержками 900/400/100/1000 мс, затем 8 кадров `walk_*` по 100 мс. Привязки указаны отдельно для каждого тега: X 15, 18 или 20; Y 85. Перемещение задаёт игровой контроллер, циклы нарисованы на месте.

## Unity

Набор импортирован как `Polished`. Сцена начинает с `Polished/idle_s`. WASD / стрелки выбирают соответствующие восемь walk/idle; при повороте Animator сохраняет фазу шага. `Space` включает исходный танец из `motion_next`, его кадры и задержки сохранены. Прежние циклы доступны в архиве.

## Исходники и воспроизведение

Рисунки созданы встроенным **`image_gen.imagegen`** по собственным референсам Алисы. Выбранные результаты сохранены в `source/*_generated.png`. Точные промпты находятся в [source/imagegen_prompts.md](source/imagegen_prompts.md) и соседних `*_prompt.txt`; исправления фронтального выреза и задней диагонали — в `South_neckline_prompt.txt` и `NorthEast_correct_prompt.txt`. Неиспользованные варианты сохранены в `source/studies`.

Метод сравнения ракурсов и опорных поз сверялся с [SLYNYRD, Pixelblog 55 — Top Down Character Animation](https://www.slynyrd.com/blog/2025/3/24/pixelblog-55-top-down-character-animation). Рисунки стороннего персонажа не включены в ассеты.

`source/build.py` регистрирует рисунки по общим ориентирам причёски, талии, подола, чулок и стоп, переносит их на исходную сетку ближайшим соседом и сопоставляет с исходной палитрой из 20 цветов. Для каждой ориентации используется одна калибровка на все 12 поз. Параметры сохранены в `source/calibration.json`.

Из корня проекта, Python с Pillow и NumPy:

```powershell
python alisa/motion_polish/source/build.py
python alisa/motion_polish/source/preview_video.py
python tools/sync_unity_art.py
```

Затем в Unity: **Alisa → Обновить клипы из атласов**, **Проверить импорт и Animator**, **Проверить управление**. Сборщик проверяет 96 ячеек, бинарную прозрачность, палитру, длительности и побайтовое совпадение композита четырёх слоёв Aseprite с PNG-кадрами.

MP4 использует FFmpeg DLL установленного Blender 5.1. Экспорт проверяется обратным декодированием всех кадров и сравнением временных меток и изображения с исходным рендером.
