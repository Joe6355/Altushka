# Алиса — проверочный цикл ходьбы

Один цикл ходьбы по диагонали к камере: 10 кадров по 100 мс, кадр36×86.
Поза рук и рисунок верха взяты из исходной Алисы. Лицо, кофта, волосы и юбка используют исходные пиксели и исходное движение. Верх стабилизирован целочисленным переносом по шее.

Для ног отдельно заданы десять силуэтов опоры и переноса стопы. Контуры, колени и обувь отредактированы по кадрам. Генерация новых изображений, IK и упругие деформации в этой версии не использованы.

## Просмотр

- Alisa_source_comparison.gif — слева исходный танец, справа новый цикл ходьбы.
- Alisa_walk_study.gif — ходьба крупным планом.
- Alisa_walk_study.mp4 — пять секунд движения по прежней площадке.
- Alisa_walk_study.aseprite — десять редактируемых кадров, тег walk_down_left.
- Alisa_walk_study_atlas.png — горизонтальный атлас360×86.
- Alisa_walk_study.json — координаты и длительности кадров.
- Alisa_walk_study_poster.png — кадр видео.
- source/ — исходные силуэты и сборка.

PNG и кадры Aseprite сверены побайтно. Пиксели верхней части совпадают с исходными после целочисленного переноса. Опорная стопа удерживается в пределах одного исходного пикселя. Видео декодировано:250 кадров,5 секунд.

Это проверка одного ракурса и одного цикла, прежде чем продолжать работу с другими направлениями.
Для повторной сборки на этом ПК: Python с numpy и Pillow, source/render.py. Для кодирования используются библиотеки FFmpeg установленного Blender5.1. Исходный атлас берётся из recolor/blue_eyes/Altushka_blue_atlas.png в этом проекте.
