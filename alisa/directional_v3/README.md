# Алиса — шесть направлений v3

Передние диагонали игрового персонажа теперь подключены к проверочному `../step_contact`; остальные четыре направления используют этот набор. Сохранённая v3 и её превью доступны для сравнения.

Текущая правка после уточнения: обычная ходьба на **A/D** и исходный танец приняты, остальные направления заменяются. Новый набор содержит ходьбу к камере, от камеры и четыре диагонали с соответствующими стойками. Это проверочный рисунок для дальнейшей визуальной оценки в игре.

Размер ячейки **36×86 пикселей**, привязка стоп `(18,85)`, PPU 16. Для каждого направления: **12 отдельных фаз ходьбы по 80 мс**, полный цикл 960 мс; четыре фазы idle по 600 мс, цикл 2400 мс. Принятая ходьба A/D сохраняет свои прежние кадры и тот же цикл 12×80 мс.

Текущая правка сосредоточена на ногах и рывках корпуса, по уточнению пользователя. Головы и лица оставлены пиксель в пиксель от первой v3. У корпуса амплитуда по высоте уменьшена с двух до одного пикселя. Убрано автоматическое смещение готового слоя ног к нижней строке: теперь каждая поза имеет собственный контур и закреплённое начало бедра. Юбка отделена от кистей, кожи бёдер и чулок; её подол следует за тазом с задержкой одной фазы. В шагающем корпусе не подменяется прямоугольный кусок другой моделькой кофты.

Голова каждого основного ракурса закреплена одним рисунком и перемещается по целым пикселям; лицо не перерисовывается между фазами. Спереди фронтальный рисунок, сзади закрытая спина и затылок. Ноги отредактированы покадрово по подходу принятого бокового шага: две разные ноги с чередующейся опорой и более спокойным восстановлением. В idle меняются только внутренние тени кофты, без рывков её контура. Правые диагонали отражены из левых целыми кадрами, со сдвигом фазы на полцикла.

## Исходники и генерация

Основа новых ракурсов создана **встроенным инструментом imagegen**, без CLI/API. Исходный дизайн и принятый A/D переданы как референсы, размерная схема — как позиционный ориентир. Результаты скопированы в `source/`; проект не зависит от файлов в кэше генератора.

В текущей правке новых генераций нет: редактируются сохранённые нативные Aseprite-исходники. Предыдущая 8-фазная версия, её атлас, сборка и видео сохранены в `source/history/initial_v3`, чтобы можно было сравнить и вернуть конкретную правку.

Точные финальные запросы и дополнительные пробы сохранены:

- `source/prompt_s.txt`, `source/prompt_n.txt` — исходные фронтальная и задняя серии.
- `source/prompt_sw.txt`, `source/prompt_nw.txt` — исходные диагональные серии.
- `source/prompt_sw_legs.txt`, `source/prompt_nw_legs.txt` — дополнительная проверка ног. Её результаты сохранены как `*_legs_generated.png`, но не используются в игровом атласе: генерация повторяла ведущую ногу.
- `source/Identity_reference.png` — оригинальный дизайн и принятый профиль; `Guide_*.png`, `*_walk_template.png` — ориентиры поз.
- `source/Native_*.aseprite` — первые рисунки после переноса на нативную сетку и очистки палитры.
- `source/Legs_s.aseprite`, `source/Legs_n.aseprite`, `source/Legs_sw.aseprite`, `source/Legs_nw.aseprite` — 12 фаз ног и нейтральная стойка в двух слоях. Файл сборки читает эти редактируемые исходники, а не создаёт их заново.
- `source/Head_*.png` — постоянные рисунки головы для проверки совпадения пикселей.
- `source/Skirt_*.png`, `source/Torso_*.png` — очищенное разделение одежды и кистей.

Сохранённый числовой референс движения из `confident_walk/source/reference/Walker.js` используется только `pose_plan.py` для позиционных схем. JavaScript референса не выполняется и не входит в Unity. Схемы не являются финальной графикой.

## Сборка

Установленный Aseprite 1.3.18.6 выполняет перенос, нативные правки и экспорт. Из корня репозитория:

```powershell
# Первичный импорт рисунков; повторный запуск заменит Native_*.aseprite.
& 'C:/Program Files (x86)/Steam/steamapps/common/Aseprite/Aseprite.exe' --batch --script-param "root=$((Get-Location).Path)" --script 'alisa/directional_v3/source/import_generated.lua'
# Первичное создание покадровых правок; заменяет только Legs_*.aseprite.
& 'C:/Program Files (x86)/Steam/steamapps/common/Aseprite/Aseprite.exe' --batch --script-param "root=$((Get-Location).Path)" --script 'alisa/directional_v3/source/edit_walk_legs.lua'
# Обычная пересборка после редактирования сохранённых Aseprite-исходников.
& 'C:/Program Files (x86)/Steam/steamapps/common/Aseprite/Aseprite.exe' --batch --script-param "root=$((Get-Location).Path)" --script 'alisa/directional_v3/source/build.lua'
python alisa/directional_v3/source/export_video.py
python tools/sync_unity_art.py
```

GIF рендерит Aseprite; Python кодирует MP4 через существующие FFmpeg DLL Blender и проверяет обратное декодирование. Python не рисует и не изменяет спрайты.

Импортёр обновляет обычные `.anim` из этого набора. Текущая команда **Alisa → Применить проверочную походку** подключает передние диагонали из StepContact; четыре остальных направления v3 сохраняются. Сцена, игровой ввод, физика, связи A/D и состояние Dance сохраняются. Порядок текущего запуска описан в `../step_contact/README.md`.

## Проверено

- 96 ячеек 36×86, бинарная прозрачность, отсутствие обрезки по бокам и разрывов между крупными частями тела. В каждой ходьбе 12 разных кадров.
- Стопы лежат в диапазоне глубины 81–85, без автоматического изменения высоты всего слоя ног. Между соседними кадрами нижняя граница меняется не больше чем на два пикселя. Это проверка скачков контура, а не доказательство идеального сцепления стоп с полом.
- Пиксели головы совпадают с первой v3, амплитуда её движения до 1 px; точные отражения диагоналей со сдвигом на шесть кадров; в задних видах нет голубых глаз. В слое юбки нет перенесённой кожи бёдер.
- Хеши семи принятых файлов, включая оригинал танца, боковой Aseprite/атлас и три Unity-клипа, совпадают с состоянием до правки. Проверка повторена после импорта Unity.
- MP4: 150 кадров / 15,12 с и 240 кадров / 15,52 с; метки времени совпадают с GIF, максимальная проверенная ошибка YUV — 1.
- Unity импортировал 13 атласов, 82 клипа, 681 исходный спрайт. Проверка импорта и изолированного Animator завершилась успешно.
- Проверка PlayerInput в Play от 10 ноября 2026: восемь направлений и выбранные клипы, скорость диагонали, остановка в idle, прерывание танца, короткое нажатие и коллизии границ пройдены.

Автоматические проверки подтверждают целостность файлов и игровые связи. Художественная оценка новой походки остаётся за просмотром в движении.
