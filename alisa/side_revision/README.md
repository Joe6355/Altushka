# Алиса — пробная правка одного бокового шага

Отдельный проверочный цикл после отклонённого набора `motion_polish`. **36×86 пикселей, 12 кадров по 80 мс, цикл 960 мс.**

Голова и лицо взяты из прежнего бокового `side_walk/Alisa_side.aseprite`. Во всех кадрах их пиксели совпадают с этой основой; меняется только целочисленное положение по высоте. Кофта использует две прежние фазы, руки остаются на бёдрах. Контуры ног заданы отдельно для каждой из двенадцати поз в Aseprite; подол следует за движением с задержкой.

Проверяется только боковой шаг вправо. Это проба для оценки рисунка и механики движения перед работой над остальными направлениями.

## Сборка

Этот цикл редактируется и экспортируется установленным Aseprite через его [Lua API](https://www.aseprite.org/api/). Новые генерации рисунков для него не использованы. Исходный боковой набор сохранён отдельно.

В Unity клип `SideRevision/walk_side_right` подключён к боковой ходьбе игрового персонажа. Влево он отражается через `SpriteRenderer.flipX`. Управление и состояния описаны в `unity/Alisa2D/README.md`.

Из корня репозитория:

```powershell
& 'C:/Program Files (x86)/Steam/steamapps/common/Aseprite/Aseprite.exe' --batch --script-param "root=$((Get-Location).Path)" --script 'alisa/side_revision/source/build.lua'
```

`source/build.lua` содержит покадровые контуры и движения слоёв, собирает нативный Aseprite и экспортирует превью через сам редактор. Проверяются совпадение головы с основой, отсутствие обрезанных контуров, бинарная прозрачность и удержание носка на месте во время опоры. Отчёт — `source/aseprite_report.txt`. Эти проверки подтверждают свойства файлов; визуальный результат оценивается отдельно по превью.

`python alisa/side_revision/source/export_video.py` конвертирует экспортированный Aseprite GIF в MP4 через FFmpeg DLL Blender 5.1 и проверяет обратным декодированием 60 кадров и их временные метки.
